Parcialito Assembler

Ejercicio 1: Traducir el siguiente código en C a ASM de la máquina virtual.

typedef struct _ln {
    short int valor;
    void* dato;
    struct _ln* sig;
} ln;
 
void** buscar (ln* lista, short int valor) {
    register void** ret = NULL;
    
    if (lista != NULL)
        if (lista->valor == valor)
            ret = &(lista->dato);
        else
            ret = buscar(lista->sig, valor);
    
    return ret;
}

Ejercicio 2: Utilizando la subrutina del ejercicio 1, desarrollar la subrutina BTN_LIST, y todas las necesarias, para resolver la siguiente tarea:

Recibiendo como parámetros un árbol binario (btn**) y una lista (ln*), desvincular del árbol original aquellos subárboles cuya clave de la raíz coincida con el valor del nodo de la lista y asignar su referencia en dicho nodo.

La subrutina principal debe coincidir al encabezado:

void btn_list (btn** arbol, ln* lista)
typedef struct _btn {
    short int clave;
    struct _btn* izq, der;
} btn;
